# バージョン0.2.0の検証結果と残作業

確認日：2026年9月17日（日本時間）。旧版の記録とは分離しています。

## 記録の確認方法

実行ログ、JSONレポート、英語・日本語の画面画像は、ソースリポジトリの
`verification/` フォルダーに保存しています。入口は
[検証記録一覧](../verification/README.md)です。
各実行の `results.json` に、検証したZIPの容量・SHA-256・実行コマンド・終了コードを記録します。
配布ZIPを作り直した場合は、ハッシュが異なるため同じ検証結果として扱わず再確認します。

## 確認項目

| 項目 | 確認方法 |
| --- | --- |
| 配布ZIPの構造・容量・ネイティブバイナリ非同梱 | `publication.log` と `results.json` |
| 14件の自動テスト | `unit-integration.log`。PMTiles有無、属性型、編集・選択、基本チェック失敗時の出力停止など |
| 英語・日本語の作成画面 | `gui-en.log`、`gui-ja.log` と対応する画像 |
| 詳細検証の未実施表示・ガイド | GUIテストで文言とガイド内容を照合 |
| PMTilesの実表示 | `browser.log`。Edgeで描画地物が存在し、JavaScript・地図エラーがないこと |
| 成果物の外部詳細検証 | `external-validation.json`。既存の開発用rashid 0.1.8で別途確認 |
| 一般公開リポジトリ・Issues | `verification/github-status.json` |

自動テストとGUIは、配布ZIPを展開したフォルダーからプラグインを読み込みます。
展開先に `_vendor` が存在しないことと、ソース作業フォルダーへ読み込みが戻っていないことも検査します。
外部詳細検証の成功は開発時の確認であり、利用者の新しい出力を自動的に検証済みにするものではありません。

## 公開前の残作業

| 項目 | 現在の状態・完了条件 |
| --- | --- |
| GitHubへのソース・README公開 | リポジトリ公開・Issues有効は確認済み。README取得は404。ソースと文書をアップロードし、未ログインで閲覧できることを再確認する |
| QGIS公式への申請 | 未実施。公開ソースに対応するZIPを提出する |
| 公式セキュリティスキャン・審査 | 未実施。ローカルの公開前チェックを公式承認として扱わない |
| 外部検証手順の新規導入試験 | 既存開発環境での検証は成功。uv未導入の利用者環境からの導入手順は別途試験が必要 |
| QGISプラグイン管理画面の「ZIPからインストール」操作 | ZIP展開・読込試験とは別。実際の操作経路の確認状態は検証記録一覧に明記する |

## 対応範囲を広げる前の残検証

- Linux・macOS・QGIS 4：このWindows環境では実機試験を行っていません。対応環境として宣言する前に試験が必要です。
- Portolan Browser：同梱のMapLibreプレビューとは別の製品であり、独立した互換性試験は未実施です。
- 公開先のCORS・HTTP Range：公開先が未設定のため未実施です。公開後に検証します。
- 大規模で複雑なポリゴンや高密度タイル：小規模データの成功では性能を保証できません。旧版の点データ性能記録を新版の性能結果として流用しません。

## 再実行

Windowsの検証済みQGIS環境では、リポジトリのルートから次を実行します。

```text
python scripts/verify_release.py --qgis-python "C:/Program Files/QGIS 3.44.13/bin/python-qgis-ltr.bat"
```

ブラウザ試験には開発環境のPlaywrightとEdgeが必要です。
外部詳細検証の試験には旧開発環境の検証ライブラリを使用します。利用者向けZIPには入りません。
失敗した項目も終了コードとログを保存し、結果を成功へ置き換えません。
